About Grabr

A modern, local-first file downloader with parallel chunked fetching, speed tracking, and crash-resilient resuming.

GitHub Repo NPM NPM Package

Guides & Tips

  • 🔌 Chrome Extension Install the integration extension to capture browser clicks and route downloads automatically.
  • ⚡ Parallel Chunks Files are split into concurrent connections for speed. Default is 4 chunks, custom up to 16 chunks.
  • 💻 CLI Management Control downloads from the terminal: 
    grabr add <url>
  • 💾 Crash Resilient If your session is interrupted, Grabr retains chunk state in ~/.grabr/, allowing seamless resumes.

🔌 Chrome Extension Integration

You can automatically capture browser downloads and right-click links to send them to this Grabr interface!

Step 1: Load Developer Extensions Open Chrome and navigate to chrome://extensions, then turn on the Developer mode switch in the top-right corner.
Step 2: Load Unpacked Click the Load unpacked button in the top-left and select this folder from your machine: 
/home/soufiane/Projects/grabr/extension

Once loaded, you can configure your downloads size filter, concurrent chunks, and directories by right-clicking the Grabr extension icon and selecting "Options".
