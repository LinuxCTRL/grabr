🔌 Browser Extension Integration

You can automatically capture browser downloads and right-click links to send them to this Grabr interface!

Step 1: Enable Developer Mode • Google Chrome: Open chrome://extensions and enable Developer mode (top-right).
• Microsoft Edge: Open edge://extensions and enable Developer mode (bottom-left).
• Mozilla Firefox: Open about:debugging#/runtime/this-firefox.
Step 2: Load the Extension • Chrome / Edge: Click Load unpacked and select the directory below.
• Firefox: Click Load Temporary Add-on... and select the manifest.json inside the firefox folder.
